Set up sync

YANTA keeps your notes in a folder on disk. Pick that folder once — then use any sync tool you trust to mirror it between your devices.

Recommended: Syncthing
Free · open-source · end-to-end encrypted · peer-to-peer · no cloud account.
  1. Install Syncthing on this device and any device you want to sync with. syncthing.net
  2. Add a folder in Syncthing — anywhere you like (e.g. ~/Documents/YANTA-Sync) — and share it between your devices.
  3. Pick that same folder below. Repeat on each device.
Also works with: Dropbox, iCloud Drive, Google Drive, an SMB share, a USB stick — anything that keeps the folder in sync. Inside the folder YANTA writes plain .md files alongside a small .yanta/ directory of conflict-free sync data.
